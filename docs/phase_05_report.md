### 2.1 CHOLMOD vs CG+AMG on 10 mini samples (all configs, single thread)

| Quantity | max (median) relative difference |
|---|---|
| T1 cumulative current | 6.0e-07 (median 1.3e-07) |
| T2 effective resistance | 2.7e-08 (median 2.0e-09) |
| T3 current / voltage | 3.9e-06 (median 5.1e-07) / 1.1e-06 (median 1.6e-07) |
| T4 Omniscape cumulative current | 4.0e-07 (median 2.6e-07) |

Converged with both solvers: pairwise True, advanced True,
omniscape True. Kirchhoff residual (full precision, exact graph): CHOLMOD
2e-14–6e-10,
CG+AMG 3e-07–4e-05.
Median wall time (s): pairwise 0.56 (CHOLMOD) vs 0.82 (CG+AMG);
advanced 0.085 vs 0.087;
omniscape 7.2 vs 7.0.

**Conclusion:** CHOLMOD is exact to ~1e-12, as fast or faster, and — unlike CG+AMG — never aborts an
Omniscape solve (in the dev shard CG+AMG failed a whole T4 solve on a contrast-10⁴ landscape because one
window's residual exceeded Circuitscape's hard-coded 1e-4). CHOLMOD is the reference for all tasks;
CG+AMG remains the documented memory fallback (`fallback_solver` flag).

### 2.2 Determinism (5 samples solved twice per solver, `JULIA_NUM_THREADS=1`, BLAS threads 1)

| Solver | pairwise bitwise identical | Omniscape bitwise identical |
|---|---|---|
| CHOLMOD | True | True |
| CG+AMG | True | True |

Both are bitwise reproducible single-threaded. Production jobs use one Julia thread; CHOLMOD/BLAS get the
allocated cores (`OPENBLAS_NUM_THREADS = SLURM_CPUS_PER_TASK`), which we have not yet verified to be
bitwise stable across different core counts — the mini run (4 cores) is the reference machine setting.

## 8. Deviations / findings (all in `DECISIONS.md`)

- Omniscape reference solver = CHOLMOD (CG+AMG aborts whole solves on high-contrast windows).
- QC residual threshold 1e-6 instead of the brief's 1e-8: the double-precision floor for contrast-10⁴
  advanced systems is ≈ 1e-8 (observed 2.3e-8 with CHOLMOD); CG+AMG sits at 1e-6–3e-5, so 1e-6 still
  separates the solvers. The float32-recomputed residual is recorded but not a flag.
- Pair convention (node i grounded, 1 A at node j) and supernode residual for focal regions.
- JIT warm-up added after the first probe showed ~7 s of compile time inside single-sample jobs.
- XL Omniscape block 17 → 33 to keep solves under ~10 min; XXL provisional.
- `HF_ORG` still `Xirro`: the owner's placeholder "<correct name>" was not filled in.
